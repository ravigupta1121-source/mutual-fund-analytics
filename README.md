# Mutual Fund Analytics Project

## Project Overview
This project focuses on Mutual Fund Analytics using Python, Pandas, SQLite, SQL, Power BI and API-based data collection. The objective is to ingest, validate, and analyze mutual fund datasets for further reporting and dashboard development.

## Tasks Completed
- Project structure setup
- Python virtual environment configuration
- Required libraries installation
- API integration for fetching NAV data
- Saving NAV data into CSV format
- Data ingestion and validation
- Loading and analyzing CSV datasets
- Data quality checks (missing values and duplicates)
- Data quality summary report creation
- GitHub repository setup and version control

## How to Run
Run the master pipeline:

## Setup Instructions

1. Clone the repository
2. Open project in VS Code
3. Install required packages

pip install -r requirements.txt

4. Run the pipeline

python run_pipeline.py

## Dataset Descriptions

- AUM by Fund House: Fund house wise AUM data
- Scheme Performance: Mutual fund return and risk metrics
- Investor Transactions: SIP and investor activity data
- Benchmark Indices: Market benchmark performance data

## How to Open Dashboard

1. Open Power BI Desktop
2. Open the Mutual Fund Dashboard (.pbix) file
3. Refresh data if required
4. Use slicers and filters for analysis
